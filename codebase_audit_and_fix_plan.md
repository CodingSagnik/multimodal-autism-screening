## Part B — Summary of the Data Flow Problem

```
Current Broken Data Flow:
═════════════════════════

 mchat_results.csv (6,075 rows)           AV-ASD dataset (928 clips)
 IDs: PATIENT_00000..PATIENT_06074        IDs: -5OJ2xYXfsc_19_30, etc.
          │                                         │
          ▼                                         │
 mchat_embedded.pt (6,075 embeddings)     ┌─────────┼──────────┐
 ⚠️ CONTAINS LEAKED A1–A10 answers       │         │          │
 ⚠️ IDs don't match any video IDs        │         │          │
 ⚠️ NEVER USED by fusion pipeline!       ▼         ▼          ▼
                                    video .npy  audio .npy  text .npy
                                    (171 files) (172 files) (171 files)
                                         │         │          │
                                         └────┬────┘          │
                                              │    ┌──────────┘
                                              ▼    ▼
                                    MultimodalAutismDataset
                                    (171 aligned samples)
                                              │
                                              ▼
                                    Fusion Model trains on:
                                    • Video: real landmark behavior ✅
                                    • Audio: real MFCC features ✅
                                    • Text: symptom-label-derived embeddings ⚠️
                                            (leaks label info into features)
```

**Root Cause**: Two completely disjoint datasets were treated as one pipeline. The M-CHAT clinical data (6,075 patients) has no relationship to the AV-ASD video data (171 clips). The text modality for the 171 video clips is actually just DistilBERT-encoded symptom annotations from `dataset.csv` — encoding the very labels the model is trying to predict.

## Part C — Implementation Fix Plan (Status: ALL RESOLVED & VERIFIED)

> [!NOTE]
> All 7 steps in the audit and fix plan have been implemented, tested, and empirically validated.

### Step 1: Fix the Text Modality — Remove Leakage from Video Text Embeddings [RESOLVED]

**Action Taken**:
- Implemented `src/data_processing/generate_video_text_embeddings.py` to synthesize strictly label-agnostic, objective clinical screening narratives from video recording interval metadata (timestamps, duration, and standardized pediatric observation protocol).
- Re-extracted 171 dense 768-dim embeddings with DistilBERT (`distilbert-base-uncased`, CLS pooling), updating `video_text_embeddings.pt`, individual `.npy` files, and audit records in `video_text_narratives.csv`.
- Preserved previous leaked embeddings in `data/processed/text_embeddings/_leaked_backup/` for scientific audit traceability.
- Validated with automated test `tests/test_leakage_free.py`: 5-fold cross-validated linear probe achieved exactly the majority-class baseline ($0.830$), proving complete eradication of artificial data leakage.

### Step 2: Generate and Pass Padding Masks for Video Tensors [RESOLVED]

**Action Taken**:
- Updated `MultimodalAutismDataset.__getitem__()` in `src/data_processing/multimodal_dataset.py` to compute a `video_mask` boolean tensor (`[max_video_frames]`) marking valid temporal frames as `True` and zero-padded frames as `False`.
- Updated `MultimodalAutismClassifier.forward()` in `src/models/fusion_model.py` to accept `video_mask` and route it directly to `VisionLandmarkModel(mask=video_mask)`.
- Verified in `TemporalAttentionPooling` that padded frames receive masked softmax scores ($-10^9$) and zero attention weight.
- Enabled dual-mode execution (`modalities=("video", "audio", "text")` vs `modalities=("video", "audio")`).

### Step 3: Clean Up the Unused mchat_embedded.pt Path [RESOLVED]

**Action Taken**:
- Relocated `mchat_embedded.pt` and `mchat_embedded.csv` to dedicated standalone directory `data/processed/mchat_standalone/`.
- Updated default output paths in `src/data_processing/extract_text_embeddings.py`.
- Removed references to `mchat_embedded.pt` in `multimodal_dataset.py` so the multimodal fusion pipeline indexes only matched AV-ASD video clip embeddings.

### Step 4: Handle the Extra Audio File [RESOLVED]

**Action Taken**:
- Audited `data/processed/audio_features/` and confirmed exactly 171 `.npy` files exist, in 1-to-1 correspondence with `video_landmarks/` (171 `.npy` files).
- Verified `_align_modalities()` aligns all 171 samples with zero dropped records.

### Step 5: Add pyproject.toml for Proper Package Installation [RESOLVED]

**Action Taken**:
- Created `pyproject.toml` specifying `setuptools` build backend and automatic discovery of `src*`.
- Successfully executed `pip install -e . --no-deps` into the project environment, enabling clean `from src.models import ...` and `from src.data_processing import ...` imports across all scripts and test suites.

### Step 6: Organize Test Scripts [RESOLVED]

**Action Taken**:
- Consolidated all diagnostic and verification test scripts into `tests/`:
  - `tests/check_phase2.py`: Comprehensive integration audit of data shapes and model parameter counts.
  - `tests/check_fusion.py`: Late fusion verification (3M and 2M modes, dynamic modality weighting, backpropagation).
  - `tests/check_subnetwork.py`: Unimodal branch verification with masking and single-sample tests.
  - `tests/test_leakage_free.py`: Automated leakage-free token and linear-probe test suite.
- Removed obsolete test script from the project root.

### Step 7: Update README to Reflect Corrected Architecture [RESOLVED]

**Action Taken**:
- Updated `README.md` with:
  - Clear separation of the AV-ASD multimodal benchmark (171 clips) and M-CHAT standalone cohort (6,075 records).
  - Documentation of the leakage-free narrative synthesis approach and empirical validation.
  - Dual-mode architecture specifications (3-modality 320D vs 2-modality 256D).
  - LayerNorm stabilization across all projectors for single-sample (`batch_size=1`) inference robustness.
  - Setup and test instructions.
